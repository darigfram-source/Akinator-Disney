# Akinator-Disney.

1.Requisitos para jugar

Tener instalado Prolog y SWI-Prolog.

2. Cómo jugar

Abrir el archivo Akinator.pl en SWI-Prolog.

Dentro del archivo PL en SWI-Prolog, escribir: adivinar.

Piensa en el personaje que quieras en el juego, solo escribe: sí, no, a sus características correspondientes y el programa adivinará el personaje que estás pensando.
