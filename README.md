# Akinator-Disney.


 1.Requisitos para jugar

Tener instalado Prolog y SWI-Prolog.

2. Cómo jugar

Abrir el archivo Akinator.pl en SWI-Prolog o tu IDE favorito que sea compatible con el lenguaje Prolog.

Dentro del archivo PL en SWI-Prolog, escribir: adivinar.

Piensa en el personaje que quieras y responde con "sí." o "no." según correspondan las características del personaje que estés pensando, el programa adivinará en quién estás pensando.
